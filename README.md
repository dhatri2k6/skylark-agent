# Skylark Drones — BI Agent AI agent that answers business intelligence questions by querying monday.com boards (Work Orders + Deals) via API, cleaning messy real-world data, and using Google Gemini for conversational responses. ## Architecture - `monday_client.py` — monday.com GraphQL API client with pagination - `data_cleaning.py` — normalizes dates, text, numbers; flags data quality issues - `agent.py` — Gemini-based agent with tool-use (get_work_orders, get_deals) - `app.py` — Streamlit chat interface ## Setup 1. `pip install -r requirements.txt` 2. Create `.env` with: MONDAY_API_TOKEN, GOOGLE_API_KEY, WORK_ORDERS_BOARD_ID, DEALS_BOARD_ID 3. `streamlit run app.py` ## monday.com Configuration Boards imported from provided CSVs (Work Orders, Deals) via native Excel/CSV import. Column IDs are auto-generated by monday.com; mapped to readable titles at runtime via the `columns` API query.
